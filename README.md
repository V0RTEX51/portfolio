# Mário Luiz · Portfólio

Portfólio pessoal de Mário Luiz, desenvolvedor de software: sites, aplicativos, sistemas internos e automações sob medida.

Site estático em um único arquivo (`index.html`), sem build e sem dependências. Ele é publicado pelo GitHub Pages.

## Seções

- Apresentação
- Sobre
- Serviços
- Projetos (com filtro e estudo de caso)
- Processo
- Ferramentas
- Depoimentos
- Contato

## Como editar

- **Projetos:** edite a lista `PROJETOS` no `<script>` do final do `index.html`.
- **Foto:** troque o bloco marcado em "Sobre" por `<img src="foto.jpg" alt="Mário Luiz">`.
- **Contato:** número do WhatsApp, e-mail e links das redes ficam na seção `#contato`.

## Rodar localmente

Abra o `index.html` no navegador. Se preferir usar um servidor:

```bash
python -m http.server 8000
```
